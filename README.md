# 留白 · Empathy Agent

在本机运行的情感陪伴应用，支持中英文流式对话、跨会话记忆、情绪检索、行动复盘和联想练习。

云端大模型负责回复，可选的本地 RAG 提供情绪线索与相关参考。没有 API 配置时，可以先体验规则演示。

[开始使用](#开始使用) · [配置模型](#配置模型) · [使用指南](#使用指南) · [本地 RAG](#本地情绪-rag可选) · [新功能](#本次新功能) · [开发计划](#后续开发计划)

## 能做什么

| 功能 | 使用方式 |
| --- | --- |
| 流式对话 | 边生成边显示，支持停止、重试；可以直接说“只想倾诉”“帮我梳理”或“给我一个小行动” |
| 长期记忆 | 自动记下情绪、近况、计划和决定；新对话继续参考，可随时更正或遗忘 |
| 情绪趋势 | 在长期记忆中查看跨会话记录，区分过去的感受与当前状态 |
| 行动实验 | 围绕一个小尝试，记录假设、执行、结果、复盘与下一轮调整 |
| 陪伴情感 · 模拟 | 让表达随互动调整，支持查看、关闭和重置 |
| 联想练习 | 塔罗、周易、情绪需要卡、文字意象、场景、关键词，选择选项继续交流 |
| 公开语料库 | 启用本地 RAG 后，更新语料、重建索引、评估候选分类器与回退版本 |
| 会话管理 | 新建对话、导出当前记录、清除聊天；长时间交流时提供休息与收尾选项 |

## 开始使用

准备 **Git 和 Node.js 22.9+**。基础聊天无需 Python 或 GPU。

```bash
git clone --branch codex/continuity-quality https://github.com/yuejain/empathy-agent.git
cd empathy-agent
```

**Windows PowerShell**：

```powershell
powershell -ExecutionPolicy Bypass -File .\Start.ps1
```

脚本会安装缺失的 Node 依赖、创建 `.env` 配置模板并启动网页。已有配置会保留。

**macOS / Linux**：

```bash
npm ci
test -f .env || cp .env.example .env
npm run dev
```

打开 **[http://127.0.0.1:3000](http://127.0.0.1:3000)**。首次未配置模型时显示规则演示；按 `Ctrl+C` 停止网页服务。修改配置或代码后重新运行启动命令。

## 配置模型

编辑项目目录中的 `.env`，填写 OpenAI 兼容服务：

```dotenv
APP_MODE=live
AI_GATEWAY_BASE_URL=https://your-provider.example/v1
AI_GATEWAY_API_KEY=替换为你的密钥
AI_GATEWAY_MODEL=替换为模型ID
```

地址与模型 ID 需要替换成服务商提供的值。基础地址可包含 `/v1`、其他自定义路径，或完整的 `/chat/completions` 路径。密钥只填入本机 `.env`，不要放进网页代码或提交到 Git。

使用小米 MiMo 时，可在上述配置中设置：

```dotenv
AI_GATEWAY_BASE_URL=https://api.xiaomimimo.com/v1
AI_GATEWAY_MODEL=mimo-v2.6-pro
AI_GATEWAY_THINKING=disabled
AI_GATEWAY_TOKEN_PARAM=max_completion_tokens
```

保存后重启网页服务。可运行 `npm run model:check` 测试连接：它会发送一条固定测试消息，不发送聊天记录，可能产生少量 API 费用。页面显示“模型已配置”仅表示读到了配置。

如需切回规则演示，将 `APP_MODE` 改为 `demo`；默认的 `auto` 在模型配置全部为空时进入演示模式。演示回复来自规则模板。

## 使用指南

### 让记忆延续到下一次对话

直接聊近况即可，例如：“最近在写论文，今天有点焦虑。我决定周末先休息。”系统会分别记录活动、情绪和决定，无需逐条说“记住”。

打开 **长期记忆**，可以查看原话依据、更新事项进度、更正或删除记录，也可以分别控制：

- **自动记忆**：是否从聊天中自动保存新记忆。关闭后仍可理解本轮内容、手动添加记录。
- **回复时参考记忆**：是否将已保存的档案用于回复。关闭后不会向云端提供这些档案。

当前情绪默认有效期为 6 小时，活动 30 天，计划与决策 90 天，稳定背景 365 天；再次明确提及时可更新。推测情绪有效期更短，过期内容不作为当前事实。历史情绪仍可用于有日期的趋势参考。

**“新的对话”保留长期记忆，“清除记录”只删除当前聊天。** 要遗忘档案内容，请在长期记忆面板操作。更正或删除后，旧聊天不会继续作为模型上下文，但界面文字仍可查看。

### 做一次行动实验

打开 **行动实验**，选择已有事项或新建一个尝试：

1. 写下假设、具体行动和观察方式，例如“午饭后走十分钟，连续三天记录下午的困倦程度”。
2. 执行后记录实际结果；无效、反效果、未完成或不确定都可以保留。
3. 完成复盘，写下调整，再开始下一轮；未复盘的轮次也可以撤回。

最多保留 8 轮。聊天中也可用“行动实验：……”“假设：……”“计划：……”“观察方式：……”建立记录，再用“结果：……”和“复盘：……”补充。多个实验指代不清时，直接到面板选择对应事项。完成行动不会自动被当作实验成功。

### 调整陪伴方式

可以直接表达“先别给建议”“少问一点”“帮我继续复盘”。**陪伴情感 · 模拟** 面板展示助手的当下反应与慢心境，可关闭或重置；这是应用层的状态模拟，不代表已实现主观感受。

自动记忆和回复参考都开启时，情感状态可跨会话延续；关闭任一开关后，状态仅在本轮生效。联想练习用于表达和探索，每个会话共可开启 3 次，不用于预测命运。

## 本地情绪 RAG（可选）

启用后，本地模型分析当前消息的情绪线索，检索公开语料与有效个人记忆，再交给云端模型组织回复。页面可查看本地 RAG 状态、情绪参考与来源。

需要 **Python 3.11+**。默认使用 CPU，无需 GPU；首次安装会下载依赖、公开语料和编码器，模型与索引不随 Git 仓库分发。

在项目目录的 Windows PowerShell 中依次运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Setup-LocalML.ps1
powershell -ExecutionPolicy Bypass -File .\Train-LocalML.ps1
powershell -ExecutionPolicy Bypass -File .\Start-LocalML.ps1
```

随后在 `.env` 添加并重启网页：

```dotenv
LOCAL_ML_URL=http://127.0.0.1:3001
```

以后使用 `Start.ps1`，会一并启动已安装的本地服务。Python 服务在后台独立运行，需要单独停止：

```powershell
powershell -ExecutionPolicy Bypass -File .\Stop-LocalML.ps1
```

在网页 **语料库** 中更新公开语料、重建索引，或设置每日/每周更新；自动更新默认关闭，仅服务运行期间有效。爬虫只处理配置好的公开来源，不是聊天中的实时联网搜索。

已有模型时再次运行 `Train-LocalML.ps1`，只训练和评估候选，不更新语料与索引；通过双语验证门槛后才替换现用版本。当前中文人工验证覆盖不足，训练完成不代表候选已启用。安装细节与分阶段操作见 [本地模型指南](docs/LOCAL_ML.md)。

## 本地数据与隐私

- 默认在 `.data/` 中以未加密文件保存聊天、长期记忆与行动记录。个人聊天不会自动加入公开语料库或用于训练。
- 使用云端模型时，当前消息、有效聊天上下文、相关记忆、检索参考及表达状态会发送给你配置的服务商。本地 RAG 不意味着完整离线聊天。
- 记忆身份绑定当前浏览器；支持同一浏览器跨会话，不支持跨浏览器或跨设备同步。清除 Cookie 后无法自动找回原档案。
- 当前聊天只保留最近 10 轮，导出也是当前加载的文字记录；长期档案独立保留。删除记忆不会同步擦除旧聊天文字或历史备份。
- 设置 `SESSION_PERSISTENCE=false` 可关闭磁盘保存；此时状态只保留在运行中的进程内。密钥、数据目录、模型权重和运行产物已列入 Git 忽略规则。

需要 SQLite 存储时，可设置 `SESSION_STORAGE=sqlite`，并安装 Python 3.11+。首次启动会迁移已有 JSON 数据；迁移后不能直接切回旧 JSON。操作前请阅读 [存储与迁移说明](docs/PERFORMANCE.md#python-存储的使用与迁移)。

应用仅监听本机地址，面向个人使用。AI 的情绪判断和回复可能出错，不提供诊断或医疗服务。

## 本次新功能

- **连续安全判断**：结合有效用户历史，区分当前证据与历史延续，避免接口异常让风险状态反复保留。
- **更完整的记忆召回**：语义检索覆盖最多 300 条有效候选，减少旧记忆、换说法和跨语言表达在检索前遗漏；更正、撤回、删除与过期规则继续生效。
- **理解与保存分开**：关闭自动记忆后，仍能识别本轮意图和交流偏好，不自动保存新的记忆、实验记录或情感状态。
- **跨轮复盘与表达连续性**：回复可参考历轮尝试、结果和调整；用户纠正、拒绝或报告负面结果时优先调整表达。
- **双语效果评测与版本门槛**：新增中英文回归评测，候选分类器需通过双语人工验证与校准检查才能启用。

这些改进仍有边界：记忆检索可能带入无关内容，中文情绪分类与概率校准仍需完善。评测范围与已知问题见 [效果评测](docs/EVALUATION.md)。

## 后续开发计划

按以下顺序推进，尚未完成的内容不会作为现有功能宣传：

1. **补齐双语真实效果评测**：扩充现代中英文对话与独立人工标注，完善分类校准，并评估真实公共语料库的检索相关性。
2. **进一步减少无关记忆**：改进相关性过滤、排序和无结果判断，在保留旧记忆、跨语言召回能力的同时减少错误引用。
3. **提升长期复盘与表达质量**：完善多事项指代、结果追踪与情绪趋势解释，用长对话和人工评价验证回复是否准确、有帮助、尊重边界。
4. **完善数据管理**：增加备份与恢复、完整档案导入导出、迁移校验，改进长期使用下的数据加载。
5. **继续优化响应速度**：测量云端等待和本地检索成本，优化调用、上下文长度与编码批次；按实际收益决定进一步的 Python 迁移。
