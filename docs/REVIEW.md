# 代码审阅与本地可用性验收

审阅日期：2026-10-07。上游基线：`fe4d453`。原始仓库：https://github.com/yuejain/empathy-agent 。

## 审阅结论

上游 TypeScript 能编译，但不能据此认定聊天可用：没有本地 HTTP 服务；构建不复制前端；SSE 的发送和解析约定不一致；主回复是随机模板；多项能力仅在库中存在，未接入实际请求流程。

本次以“可独立启动、功能能从浏览器走通、失败能恢复”为完成标准，保留情绪标签、风险规则、卡牌数据和阶段约束，重建主运行链路。改动仅在克隆的新目录中，不修改父目录的研究工程。基础版本已通过 PR #1 合并；未发布公网网站。

## 已修复的问题

| 问题 | 后果 | 当前处理 |
| --- | --- | --- |
| dev 脚本依赖未安装的 EdgeOne CLI，缺少本地 HTTP 服务 | 无法按文档启动 | Node HTTP 服务、资源构建、`.env` 加载、Windows 启动脚本 |
| 后端发 `event:`，前端只接收以 `data:` 开始的帧 | 正常结果被丢弃 | 独立 SSE 解析器、命名事件/分片/CRLF/心跳用例 |
| LangGraph 消息流包装了没有真正调用模型的节点 | 模板或空回复，依赖冗余 | 直接编排与明确事件；移除未使用的 LangChain/LangGraph 依赖 |
| 模型名被硬编码，基础路径重复追加 `/v1` | 自定义服务失败 | 统一 gateway 和可配置模型，兼容路径标准化 |
| 外部请求无超时、无完整取消链路 | 长时间等待，停止无效 | 超时、断连取消、停止接口、锁释放 |
| 解析失败默认困惑情绪，情绪数值未经验证 | 无依据显示情绪，可能出现非法数值 | Zod 验证，未识别时保持中性，标注词典降级 |
| 状态转换中多项用户信号恒为 false | 卡在入口，行动/复盘不可达 | 直接对话入口、信号处理、阶段序列测试 |
| 会话派生用户 ID 与默认会话易共享 | 多个访问者可能混用记录 | 所有者 cookie + 完整会话 ID，跨所有者读写删除测试 |
| 历史仅在内存，安全阻断不计入完整轮次 | 重启丢失、轮次/状态不一致 | 原子 JSON 存储、统一状态更新、有界历史 |
| 记忆管线未接入，使用数恒为零 | 不能记住信息，文档夸大 | 主流程接入可查看/遗忘的显式记忆，不调用伪向量服务 |
| 首轮抽牌信号不可达，入口只给欢迎语 | 无法实际抽牌 | 使用 22 张牌数据，输出牌名、描述与三个联想方向 |
| 安全层可能被默认低风险覆盖；否定词范围过宽 | 危机信号降级 | 高风险规则优先，仅邻近否定生效，增加已发生过量服药场景 |
| 危机输出是内部“终止对话+热线”指令 | 缺少可读的帮助信息 | 本地支持性回复、当地紧急资源、即时安全确认，持续支持不等待网络 |
| 用户/模型文本直接拼接 innerHTML | HTML 注入 | textContent、CSP、浏览器注入回归用例 |
| 固定质量分 0.85 | 用户误以为质量经过测量 | 去除前端质量评分；内部过滤器评分仅是启发式，不对外声称有效性 |
| API 错误无可靠反馈 | 假成功、记录污染、无法重试 | 脱敏错误事件，不保存失败或取消的半轮记录，恢复输入 |
| Windows PowerShell 5.1 将无 BOM 的中文脚本误读为系统编码 | 启停脚本出现解析错误 | 启停脚本改为 UTF-8 BOM，验证 5.1 解析与实际停止 |
| MiMo 默认深度思考会增加短对话等待时间 | 本次两轮初测约 21–33 秒 | 增加可选 thinking 和 token 上限字段配置；MiMo 使用 disabled 与 max_completion_tokens |

## 本地训练与流式扩展

2026-10-07 已实际下载公开人类语料、清洗并训练分类头与生成 LoRA，接通本地服务和网页模型切换。中英文等量的生成训练池及检索库已经落盘，分类训练数据的语言覆盖仍不均衡。详细数字、训练范围和局限见 [TRAINING_RESULTS.md](TRAINING_RESULTS.md)。原始数据、权重、会话、密钥及下载缓存均被 Git 忽略。

网页接收上游真实增量内容，最终确认完整后才写入会话。断流、输出预算耗尽、空白输出和停止均不提交半轮记录。真实本地模型和 MiMo 的构造输入验收由 `scripts/verify-live.cjs` 执行：本地最终记录在 `artifacts/local-model-live.json`，MiMo 记录保留在 `artifacts/live-before-sampling.json`。本地首段约 0.19–1.89 秒，MiMo 一次首段约 7.42 秒、整轮约 8.71 秒，均是少量样本，不代表稳定性能。6 项 Python 单元测试通过，覆盖清洗、评估分区去重优先和检索相关性门槛。

实际试聊仍观察到本地模型偶发角色混淆和编造背景，已在界面和训练记录中标注实验性质；没有以这些调用宣称质量验收达标。当前建议使用 MiMo 回复，本地分类检索提供参考，需要离线时可手动选择小模型。

## 长期记忆重构（2026-10-09）

删除原模拟记忆存储、哈希向量、图检索和摘要管线，接入按浏览器所有者保存的 v2 长期档案。默认从聊天主动提取当前情绪、活动、计划、决定和稳定背景；不要求逐条确认。规则与真实模型提取结合，使用当轮原话证据、确定性、有效期、替代关系和上下文版本控制污染。新增管理面板与接口、旧版迁移、版本冲突检查、跨会话互斥和聊天/记忆原子提交。完整行为见 [MEMORY.md](MEMORY.md)。

- 48 项 Node 核心/接口测试通过，新增双语提取、提问与陈述区分、语义依据、跨会话、重启、过期、撤回、引用污染、旧版迁移、版本冲突、存储失败与中断回滚用例；安全支持状态下仍可执行遗忘。
- 12 项 Chromium 测试通过：桌面和手机分别验证原有聊天与游戏、长期记忆新会话延续、编辑、结束、删除、开关、清空和布局。
- MiMo 构造消息实际完成两轮：首轮保存四类条目；新会话检索四条有效记忆，回复正确提到先前保存的摄影展事项；存储重开和清空通过。测试仅使用独立临时档案，不读取私人聊天。首轮约 14.96 秒，第二轮约 10.23 秒，只代表该次样本。
- 本地 Qwen3 LoRA 的同一临时档案测试也通过：两轮均完成真实流式生成并参考四类记忆，持久化与清空成功，约 7.73 秒和 0.80 秒。该测试验证接线和状态，不据此认定小模型语义提取或回答质量已充分可靠。
- 记忆数据、模型产物、真实密钥和运行日志继续排除在 Git 之外。规则无法识别所有反讽、错误陈述和语义矛盾，不能把测试通过解释为零污染保证。

## 本地情绪 RAG → 云端回复（2026-10-09）

当前主链路调整为：本地 MiniLM 编码器 + 情绪分类头 + 4,000 条语料检索 → 结构化情绪指向/回应节奏/证据 → 云端大模型流式回复。移除网页本地生成选项与 Python 生成实现；默认下载训练仅执行编码器、分类头和建库。旧 Qwen3 LoRA 权重与实验脚本保留为历史，不再加载；旧客户端 `backend: local` 和本地生成端点均返回 410，不静默转发。

- 55 项 Node 测试、14 项桌面/手机浏览器测试、9 项 Python 测试通过。新增覆盖本地只接收 `/analyze`、云端收到情绪指向及证据、倾诉意图优先、分数与强度区分、低置信度、异常数据、RAG 降级、旧客户端提示（包括独立 Fetch 适配器）与语料不污染个人记忆。CI 增加不加载真实权重的轻量 Python 测试。
- 真实本地健康状态为 `role: emotion-rag`，`generator: false`，`generator_loaded: false`；复用原有分类器及索引，不重新训练、不下载生成权重。
- 真实 MiMo 构造输入验证：中文首段约 15.61 秒、整轮 16.97 秒，携带 3 条检索参考，回应方向为倾听；英文首段约 13.07 秒、整轮 14.14 秒，方向为倾听，无合适检索片段时明确 `no_matches`。单独英文检索查询命中 2 条。以上是一次链路验收，不是性能或共情质量基准。
- 脚本使用独立内存档案与构造消息，不读取私人聊天；脱敏指标保存于被忽略的 `artifacts/emotion-rag-live.json`。历史本地生成结果不代表当前产品仍提供离线生成。

## 保留但不宣称可用的研究能力

原模拟记忆管线已删除；当前用户记忆用有界类别、词项及时效检索，不声称实现向量 GraphRAG 或 Cross-Encoder。真实公开语料向量检索和训练位于 `ml/`。多会话旅程跟踪器、部分替代入口及原有示例训练脚本仍属研究代码；不存在运行中的 Milvus、Neo4j 或 PostgreSQL。

当前长期记忆支持同一浏览器跨会话共享，尚不支持账号登录或跨设备同步。持久化文件未加密，限本机个人使用；公网服务还需独立认证、数据库迁移、运维与评估。来源链接只展示在本次回复中，刷新恢复的是文字记录。流式措辞过滤和危机规则均有覆盖边界，不能保证发现所有风险。
