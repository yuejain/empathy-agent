# 行动实验、会话节奏与模型维护

当前主流程在原有联合检索基础上增加完整的行动实验周期，并把上下文意图识别并入已有的记忆分析请求。仍是本机、单进程、同浏览器身份的应用。

## 行动实验与复盘

页面点击“行动实验”，可选择已有活动/决策，或者创建一个尝试。填写假设、具体步骤与观察方式后开始；结束时记录实际结果，再记录收获与调整。结果允许无效、反效果、未执行和不确定，完成不等于验证成功。

状态依次是 `draft → running → awaiting_review → reviewed`，任一未复盘轮次可撤回。开始需要假设、计划与观察方式；记录完成需要实际结果；完成复盘需要结果与收获；下一轮需要上一轮已复盘且填写调整。下一轮继承假设、观察方式、价值与限制，以调整作为新计划，不继承结果或成功结论。最多保留 8 轮，达到上限提示建立新事项，不静默删除旧轮次。

普通聊天会更新已有实验中的用户原话；也可用下面的明确格式创建或补充：

```text
行动实验：午休散步
假设：散步可能减轻下午的困倦
计划：午饭后走十分钟
观察方式：连续三天记录困倦程度
```

之后可以说“结果：三天都没有改善”或“复盘：目前还不支持这个假设”。多个实验并行而指代不清时，不自动把结果归到任意事项。聊天自动记录字段不自动宣布实验成功或开始下一轮；界面上的状态操作由用户控制。已有明确完成表达仍可把相关事项设为待复盘。

每个字段保留原话、时间、会话与来源；实验附在对应记忆条目中，不存在独立画像库。删除该条目或清空记忆会一并删除实验。更正事项正文会清除旧实验，避免把旧结果套到新事项；更正当前实验字段会替换该字段，修改已复盘的关键依据会退回待复盘。历史轮次供查看，若历史包含错误或不希望保留的信息，可删除整个事项后重新建立。关闭召回时不向云端提供任何实验；管理面板仍可编辑自己的记录。

云端仅接收相关实验的当前轮，最多 3 项、实验数据合计 2,600 字符。完成的实验可在询问结果/复盘时召回，不能被描述成现在正在执行的活动。更正会递增上下文版本，旧聊天不再参与后续模型输入。

## 意图与陪伴阶段

启用自动记忆时，`TURN_ANALYSIS` 一次返回记忆候选、带当前原话依据的意图和已有实验字段。它与安全评估、本地 RAG 并行；正常轮次仍为两次云端准备请求加一次流式生成，没有新增独立意图调用。只接受已知意图枚举、置信度至少 0.65 且依据来自本轮的结果；失败、低置信度或关闭自动记忆时使用本地规则，不单独再调模型。

用户明确的倾诉、探索、行动和复盘优先。旅程推荐与探索深度限制用于自动推进：到达当前阶段的探索深度时先承接、整理，不无限追问。明确希望继续探索可以继续；阶段不是心理诊断，也不是限制用户话题的资格检查。

## 会话健康交互

闲置 30 分钟、连续交流 3 小时或 50 轮时，界面提供继续、休息结束、新对话三个选择。继续会重置本轮提示计数；结束保留聊天和长期记忆，新对话沿用长期档案。也可在结束后继续发言，恢复交流。安全支持状态不弹出这些收尾提示。

`GET /api/session/health` 返回状态。`POST /api/session` 接受 `{action:"continue"}` 或 `{action:"close"}`；均遵循浏览器所有者隔离和当前回复互斥。前端可见且没有正在回复时，每分钟检查一次。

## 分类器更新与回退

“语料库 → 训练并评估新版本”运行固定的 `ml/train_classifier.py --candidate`。仅使用公开训练数据，固定现有编码器，在独立版本目录训练八个分类头；不改动当前头或公共索引。

候选和正在使用的分类器在相同保留分区上评估。发布门槛在运行前固定：必须存在至少 20 条人工标签的验证分区，每个这样的分区 macro F1 至少 0.30，且相对原版本下降不超过 0.02。弱标签不作为发布依据；测试集指标只报告，不参与选择。该门槛是工程回归检查，不证明共情质量、中文覆盖或医疗有效性。没有足够人工标签的语言不会被宣称已通过质量验证。

通过后原子更新 `models/local/classifiers/active.json`，下一次分析校验头文件哈希、标签与维度后热加载。未通过保留候选报告和原模型，界面显示原因；异常新版不替换已加载版本。可“回退上一版本”，回退也保留模型文件。自动每日/每周语料更新只采集及建库，不自动重训。

网页训练和索引维护共享文件锁；训练子进程另持分类器锁，回退也使用同一把锁，即使父服务退出也不会发生训练与回退并发覆盖。离线语料 CLI 不应与网页维护同时运行。网页启动的训练有 30 分钟超时；关闭服务会中断调度，但已经启动的子进程可能继续完成，不能当作系统常驻任务。模型及所有评估产物位于被 Git 忽略的目录。

## 清理与范围

移除旧的独立 `EmotionTracker`、转移概率矩阵、重复 `SafetyManager`、第二套共情决策、单独云端情绪分类与意图增强调用、意图历史缓存及其无效配置。保留一个对话状态机、一份有证据的长期档案、本地情绪头及统一安全链路。旧安全训练示例不再从运行库聚合导出；没有训练或部署独立的本地安全模型。

这些旧 TypeScript 导出不再兼容，仓库内调用已迁移。当前不新增图片上传分析、通用联网搜索、外部通知或账号同步，也未重写 Python Web 后端。它们是独立的新增产品能力，不应与本轮已接通的单机功能混称为已完成。

## 验证

`npm test`、`npm run test:browser` 与 `python -m unittest discover -s ml -p 'test_*.py'` 覆盖状态门槛、失败回滚、数据隔离、删除和更正、合并调用次数、手机交互、固定评估门槛及模型回退。`node --env-file-if-exists=.env scripts/verify-advanced.cjs --cloud` 使用构造消息与独立内存档案验证真实服务，不读取私人聊天。
