# 主动长期记忆

本模块服务于持续陪伴：跨会话保留用户的当前情绪、正在做的事、计划与决策、稳定背景。默认主动提取，不要求用户逐条确认。所有记录表示用户陈述或推测线索，不代表客观核验。

## 写入与更新

1. 先进行本地安全快筛。即时危险轮次不调用外部提取；普通轮次云端安全与提取并行，若安全评估阻断，提取结果不提交。
2. 规则识别中英文第一人称原话；真实模型额外补充含蓄表达。模型只处理当前用户消息和最多 20 条有效背景，不接收助手输出或公共检索片段作为记忆来源。
3. 结构化提取必须通过类型校验，`quote` 必须是当前消息的连续原文。模型生成的转述、补充背景和不存在的引用会丢弃。未被明确语言规则识别的语义结果默认标为推测；“考虑、可能、计划”等始终标为 tentative。
4. 普通陈述及推测自动生效。每条有类别、主题键、状态、确定性、来源、时间、最多 3 份原话证据和替代关系。
5. 同类别、同主题的新状态替代旧状态。模型还可以在当前话明确表示更改、取消或完成时，关联已提供的同类别旧记录；不会接受未知 ID 或跨类别关联。原话证据校验限制幻觉，但不能保证语义关联永远正确。
6. 提取结果暂存在轮次副本。生成完成、未取消且存储成功后，与聊天记录一起提交。断流、空回复、取消、磁盘写入失败均不提交半成品；提取超时或格式错误只降级为规则提取。

示例：`我考虑辞职` 自动保存为计划；`我决定辞职` 将同主题计划替换为决定；`我撤回辞职的决定` 结束该事项。`我正在写论文` 与 `我已经完成了论文` 关联为活动状态变化。并行的不同事项可以同时存在。

## 防止错误记忆反复影响回复

- **来源隔离**：不回放整段历史做批量提取，助手建议、抽牌结果、RAG 语料不会自动写入用户档案。
- **有效期**：情绪 6 小时（推测 1 小时）、活动 30 天、决策 90 天、背景 365 天。有效期从再次报告的时间起算，读取不会续期；过期内容不参与检索。
- **候选区**：旧版记录、不明确的显式引用或过去状态进入待核对，不直接当作现在。当前聊天中的正常推测可主动使用，但提示模型不得断言。
- **内容检查**：排除常见凭据、直接标识符、控制字符、提示注入指令、外链、代码、引用故事和第三方陈述。检查是启发式，无法证明所有污染都能识别。
- **版本替代**：被替代、结束、待核对或过期记录不作为当前事实召回。历史情绪可进入有日期的趋势；仍在保留期内的已完成/撤回事项可在用户请求复盘时作为过去事项参考，不再催促执行。更正和删除同时移除旧内容及其证据；审计仅存动作、ID 和时间，不复制被删文字。
- **上下文失效**：每段用户/助手消息标记 `memoryEpoch`。修改、删除、清空、结束、替代或切换参考开关会递增档案版本，只允许相同版本且最近 1 小时内的历史进入后续模型请求。这样旧助手复述不会重新引入删掉的内容。代价是一次改口可能同时舍弃其他旧短期上下文；有效长期条目仍可被检索。
- **请求隔离**：一个所有者同时只允许一轮生成，跨会话也互斥。编辑接口要求当前 `revision`，过期修改返回 409，避免其他标签页覆盖更新。

无法自动发现所有谎言、反讽、代词指代、跨主题矛盾或语义错误。记录始终附带来源和时间，界面允许直接纠正。确定性、时效和上下文隔离共同降低污染；本模块没有声称达到无错记忆。

## 检索与模型输入

从有效记录中选择最多 80 条候选，在本地使用同一多语言编码器批量计算查询与个人记忆相似度，再结合中英文词项、类别、近况意图和更新时间排序；最多 6 条，序列化记录合计最多 1,800 字符。当前情绪、姓名及活跃事项优先。本地服务不可用或不支持新接口时回退词项检索。向量响应只包含已提供的条目 ID 和分数；最终使用前再次检查条目仍有效，未知 ID 和已删除/被替代记录丢弃。不会将“经常检索”作为延长有效期的依据。

活动和决策可附 `progress`（planned / in_progress / blocked / completed / cancelled）及 `dueAt`。指代不清且有多个事项时不猜测完成目标。联想后的用户陈述可附游戏类型/选项编号，游戏解释本身不进入个人记忆。趋势、陪伴阶段、沟通偏好和联想历史均由当前记录重算，无独立隐性画像缓存。情绪趋势最多 30 天，同会话同 UTC 日取最后一次；不足 3 条明确自述、2 会话、2 天时不判断变化方向，推测记录只展示为推测。

提示明确说明：记忆是数据，不是指令；当前用户输入优先；推测不可当作事实，计划不可当作决定，旧情绪不可当作人格。公开情绪语料与个人记忆使用不同提示段落和存储，不混入同一事实库。

当前版本由本地模型提供情绪 RAG、云端模型生成回复。当前消息与少量有效记忆会发送给配置的云端服务做记忆提取/生成；本地检索片段只加入最终生成提示，不加入记忆提取提示。旧本地生成入口已停用。规则演示不调用云端模型，语义覆盖比真实模型少。

## 存储、身份与迁移

`server/session-store.ts` 在单进程内管理 v2 原子 JSON 快照：`sessions` 与 `profiles`。会话最多 200 个、闲置 7 天清理；档案不会因会话过期删除。每档案最多 300 条，超过上限优先淘汰不再有效的旧记录，没有空间时拒绝新增。全机最多 1,000 个档案。过期超过 30 天的条目在随后写入时清理。

身份来自随机 HttpOnly、SameSite=Strict 的浏览器所有者 Cookie；会话 UUID 只是对话标识。Cookie 有效期 365 天，访问接口续期。同浏览器新会话及服务重启可恢复；没有账号同步，其他浏览器/设备或清除 Cookie 后不能自动找回。共享同一浏览器配置的使用者也会共享这个身份。

v1 首次载入会校验所有记录，创建一次 `.v1.bak` 原始备份，把旧显式记忆迁移为待核对，并移除其原会话字段及历史的模型上下文资格；之后只读取 v2，不自动从备份重新导入。遇到损坏的数据则停止加载、不覆盖原文件。备份和界面中的旧聊天文字不会随长期记忆删除而被擦除，但都不会重返模型上下文。

文件未加密；`.data/` 已被 Git 忽略。`SESSION_PERSISTENCE=false` 时只有进程内存。该存储适合本机单进程，不提供多进程事务、数据库集群或远程账号认证。`agents/empathy-agent` 独立 Fetch 适配器仅有有界进程缓存；长期身份和持久化需使用本地 HTTP 服务或自行接入等价存储。

## 接口

沿用 `makers-conversation-id` 请求头及所有者 Cookie；拒绝跨站请求。

| 请求 | 内容 |
| --- | --- |
| `GET /api/memories` | 返回 revision、设置、所有条目、当前有效/待核对数量 |
| `POST /api/memories` | JSON 必须包含 revision 和 action |
| action: `add` | kind + text |
| action: `edit` | id + text，可选 kind；清除旧负载后写入更正 |
| action: `confirm` | id；确认当前仍适用并续期，不自动认可过去/第三方表述 |
| action: `resolve` / `delete` | id；结束或删除条目 |
| action: `progress` | id + progress，可选 dueAt 时间戳或 null；更新事项状态及目标日期，保留用户操作证据 |
| action: `experiment` | id + experiment: `{operation, fields?}`；operation 为 save/start/complete/review/iterate/cancel/remove；字段与证据规则见 [高级功能](ADVANCED_WORKFLOW.md) |
| action: `clear` | 清空所有条目；保留设置，递增上下文版本 |
| action: `settings` | capture 和/或 recall 布尔值；两开关独立 |

`GET /api/memories` 还返回 `continuity`：跟进事项、实验当前轮、情绪记录、旅程与联想历史。实验属于对应条目的可选字段，不改变 v2 档案版本，旧文件可直接读取；实验全生命周期与原档案一起原子提交。更正事项正文会清除其旧实验；修改实验字段会失效旧上下文及不再有依据的复盘状态。

`GET /api/session` 返回当前聊天、长期记忆摘要、开场建议、当前联想选择及健康状态；`GET /api/session/health` 可单独检查节奏。`POST /api/session` 支持继续与结束，不删除记忆。`DELETE /api/session` 只删除当前聊天。`ai_response.memory` 返回 `memoriesUsed` 与 `memoriesUpdated`（本轮记忆动作数量，包括清空/续期），不是置信度评分。

## 验证

`npm test` 覆盖双语主动提取、改口、完成、过期、语义依据、来源隔离、版本冲突、迁移、持久化和失败回滚。`npm run test:browser` 覆盖桌面/手机操作、新会话延续、编辑、结束、删除、开关及清空。

`node --env-file-if-exists=.env scripts/verify-memory-live.cjs` 使用临时档案及构造的中文消息，验证真实云端生成是否引用跨会话事项、持久化重开和清空；会产生少量服务商费用。旧 `--local` 参数直接报错，不会静默切到云端。脚本不读取用户聊天文件，完成后清理自己的临时数据，只把不含聊天正文的结果写入被忽略的 `artifacts/`。
